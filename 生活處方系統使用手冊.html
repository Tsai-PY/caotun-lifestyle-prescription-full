壹、系統簡介與核心架構

「南投縣草屯鎮生活處方完整版系統」是一套專為社區基層民眾、醫事人員、社工與社區志工設計的現代化健康生活處方資訊平台。本系統深度結合 Google Maps Platform 官方雲端 API（包含 Maps JavaScript API、Places API (New) 與 Routes API），並內建草屯鎮專屬之高精密度現有路網拓撲幾何引擎（caotun-roads.js），達成免除配額消耗亦能進行實體道路規劃的雙軌架構。

🌟 系統雙大核心模組架構
  • 第一部分：生活處方資料查詢（民眾與照護者端）： 提供依目前所在位置（地標、地址或即時手機/電腦 GPS），一鍵檢索草屯鎮全轄區距離最近的 5 個生活處方服務點，並自動計算開車、機車、單車、步行之實際道路行車時間、公里數、即時營業狀態（營業中/休息中）、門牌地址與電話，並在地圖上繪製導航路線軌跡。
  • 第二部分：生活處方資料維護（管理者與公所/衛生所端）： 採用 Google My Maps（我的地圖）直覺風格，提供六大處方圖層獨立維護，支援點選已有地標、任意座標點選、GPS定位、輸入搜尋等四大標記新增方式；具備草屯鎮界嚴格多邊形防呆檢核、重複新增防呆、照片上傳壓縮管理、還原上一步，並可隨時匯出／還原標準 KML 檔案。

參、第一部分：生活處方資料查詢操作指引

點擊網頁上方「第一部分：生活處方資料查詢」藍色方框，即可進入查詢模組。整體查詢流程分為順暢的四大步驟：

1. 設定查詢起點（位置設定）

  • 預設起點：系統預載以「南投縣草屯鎮公所周邊 (23.9742, 120.6824)」為預設查詢中心。
  • 地標／地址搜尋輸入：在「輸入我的地點（地標或地址）」欄位內輸入您所在的任何地標或門牌（如「草屯國小」、「惠德宮」或「南投縣草屯鎮中正路100號」）。
  • 點選我的位置：輸入完畢後點擊藍色「📍 點選我的位置」按鈕，系統會立即在地圖上將地圖視角移動至該處，並重新計算全鎮據點至該位置之距離。
  • 取得目前 GPS 位置：若您使用具 GPS 定位功能的手機或平板，點擊「📡 取得目前 GPS 位置」按鈕，瀏覽器跳出授權提示時請選擇「允許」，即可精準抓取現場座標作為導航起點。

2. 步驟 1：選擇生活處方類別

點擊「🤝 社交」、「🌿 紓壓」、「🍲 營養」、「🏃 運動」、「😴 睡眠」、「💊 藥物安全」任一按鈕。點選後系統會將右側地圖與左側清單即時過濾為該處方類別的專屬點位。

3. 步驟 2：選擇交通方式

支援四種交通模式切換： 🚗 開車 🛵 機車 🚲 單車 🚶 步行。 切換時，系統會依據草屯鎮實際道路速限與單行道限制，即時重新計算到達各據點的路線軌跡與到達時間。

4. 步驟 3：距離目前位置最近的五個服務點

系統依「真實路程距離」與「直線距離」排序，直接列出最接近您的前 5 處生活處方據點：

  • 每個項目標示排序編號（①～⑤）、據點名稱、直線與路程距離、以及交通工具預估行車時間（如：約 1 分鐘）。
  • 點擊任一項目即可設為目前選取的目的地，右側地圖立即繪製高對比的道路導航軌跡線段。
  • ▼ 下拉查看其餘服務點：若想查看第 6 處以後的服務點，可點開下方下拉選單自由挑選。
  • 關鍵字篩選：可在「輸入查詢地點名稱或關鍵字」欄位輸入關鍵字，即時縮小清單範圍。

5. 步驟 4：所選服務點詳細資訊與到達時間

呈現目的地之完整資料，包含：

  • 預計抵達鐘點：以目前時鐘為基準，加上交通耗時，顯示精確的預計抵達時間（例如：預計 14:28 抵達）。
  • 即時營業狀態：整合 Google Places API 即時顯示「營業中（至 18:00 關閉）」或「休息中」。
  • 詳細資訊：門牌地址、電話號碼、完整每週營業時間表與備註說明。
  • 🔍 聚焦規劃路線：點擊後地圖視角自動平移並最佳縮放，使出發起點與目標服務點完整呈現在畫面上。
  • 🗺️ 在 Google 地圖開啟外部導航：一鍵調用外部 Google Maps 網頁或手機 App，可立即啟動即時 turn-by-turn 語音導航。

6. 地圖圖面互動與直覺點選切換

💡 地圖即時指針與選取功能 在地圖畫面上，游標移動到任何服務點圖釘時，會即時顯示該服務點的名稱、說明與最新照片；在視窗內點擊「📍 點選此服務點（切換道路導航與詳細資訊）」，即可直接在圖面上將其切換為目標導航點，無需在左側清單來回尋找！

肆、第二部分：生活處方資料維護操作指引

點擊網頁上方「第二部分：生活處方資料維護」紫色方框，即可切換進入後台維護編輯模式。此模式採用 Google My Maps（我的地圖）設計規範，讓公所承辦人、社工或志工能輕鬆管理圖層。

1. KML 檔案管理與安全備份

左側頂部設有黃色外框的「KML 檔案管理」卡片：

  • 📂 載入 KML 檔（還原）：可將本機先前備份的 .kml 檔案匯入系統，系統會即時重新剖析 Placemark 與 Folder，無縫還原歷史所有資料。
  • 💾 備份 KML 檔（匯出）：維護完畢後，點擊此按鈕可將全鎮最新 270+ 筆資料打包下載為 草屯鎮生活處方群組資料_備份_西元年日時分.kml。匯出的 KML 完全相容於 Google 地球（Google Earth）與 Google 我的地圖（Google My Maps）。
  • 🔄 還原預設值：若測試修改錯誤，可一鍵將資料庫恢復至系統出廠預載的 271 筆標準資料。
  • ↩️ 復原刪除橫幅：若不小心誤按刪除，上方會出現橘色「復原刪除」警示條，點擊即可瞬間救回誤刪的點位。

2. 步驟 1：先選擇要維護的生活處方圖層

單一圖層開啟原則：本系統為避免不同處方點位在地圖上混雜導致誤選，一次僅開啟一種圖層進行維護（例如目前開啟【社交】處方圖層）。

  • 目前選中服務點卡片：為讓右方地圖擁有最大顯示視野，左側清單經過精簡優化，主要顯示目前正在編輯選中的「單一服務點卡片」。
  • 下拉切換其他服務點：卡片下方隨附單行下拉選單，可隨時點開切換至同圖層的其他服務點。

3. 地圖上方工具列：四大新增生活處方服務點功能

位於右側地圖頂部的綠色工具列，提供四種直覺靈活的資料點新增途徑：

🏪 選項 1：點選 Google Map 已有名稱標記

當草屯鎮上有新成立的店家、診所或據點已存在於 Google Maps 上時，直接在地圖上用滑鼠點選該店家圖示（POI），系統會透過 Places API 讀取官方註冊資料，並於地圖彈出確認卡，點擊「➕ 新增至【社交】圖層」即可自動帶入店名、電話、營業時間與地址。

📍 選項 2：任意選座標點新增標記

若為無特定店家名稱的戶外聚會點、榕樹下涼亭、休閒步道起點，切換至選項 2，在草屯地圖上任意位置點擊一下，即可精確建立該點座標，並跳出視窗輸入名稱與備註。

📡 選項 3：取得目前 GPS 位置

志工或工作人員親自前往現場勘查時，點擊選項 3，系統立即以現場行動裝置的高精度 GPS 座標建立新服務點。

🔍 選項四：輸入搜尋標記

在工具列的輸入欄位中鍵入地標名稱（例如「草屯鎮立圖書館」、「惠德宮」或特定路名門牌），點擊「🔍 選項四輸入搜尋標記」或按 Enter，系統自動搜尋、校驗並將視角平移至該地標以供新增。

4. 草屯鎮行政轄區邊界多邊形嚴格防呆

🛡️ 座標範圍檢核機制（Ray-Casting 136 頂點多邊形演算法） 為確保資料庫之純淨與正確性，無論透過「任意點選座標」、「GPS 定位」或「地標搜尋」，系統在新增前皆會強制執行草屯鎮多邊形交點射線檢驗：
👉 若點選座標超出草屯鎮行政疆界，系統將自動阻擋新增，並跳出提示視窗：
「您要新增的服務點位置不在南投縣草屯鎮內，請重新選擇」
有效防止誤將南投市、台中市霧峰區或芬園鄉之非轄區點位存入系統。
🚫 重複資料新增防呆 若使用者點選或搜尋已建檔於該圖層之服務點，系統會主動阻擋重複建立，並自動定位與選定該筆現有資料供查閱與修改。

5. 步驟 2：編輯服務點資料（文字、樣式、照片與刪除）

選定特定點位後，左側下方即展開專屬編輯視窗：

(1) 🎴 樣式規範

為維護系統圖層的一致性與標準化，各生活處方僅開放該圖層官方指定的原本標準色彩與專屬圖示，避免圖資色彩混亂。

(2) ✏️ 編輯服務點名稱與說明內容

  • 服務點名稱（<name>）：輸入或修改據點名稱。
  • 所屬圖層（<Folder>）：可隨時調整該據點所屬的六大處方類別。
  • 資料點說明（<description>）：紀錄開放時間、聯絡電話、服務對象、特色說明等。
  • ⚡ 自動從 Google Maps 帶入地址/電話/營業時間：點擊此功能鍵，系統自動呼叫 Places API 比對最新門牌與電話並自動填入說明欄。
  • 精準座標修正：提供緯度 (Lat) 與經度 (Lng) 欄位微調，調整後點擊「💾 儲存資料點變更」即時生效。

(3) 📷 圖片管理與上傳

  • 📁 上傳本機照片檔：支援從電腦或手機選取照片。系統內建前端 Canvas 智慧壓縮引擎，自動將照片最佳化為高品質且輕量之 Base64 資料，直接封裝入 KML 備份中。
  • ➕ 加入網址圖片：支援直接貼上外部圖片的 HTTPS 網址。
  • 相簿預覽與刪除：已上傳的照片會列於預覽區，可點擊放大觀看，或點擊「✕ 移除」刪除照片。

(4) 🗑️ 刪除服務點

點擊紅色「🗑️ 刪除」按鈕，系統會先跳出防呆確認對話框，確認後將該點從圖層移除，並自動產生復原快照以供隨時救回。

伍、無障礙規範與鍵盤操作指引

本系統遵循國家通訊傳播委員會 (NCC) 「無障礙網頁開發規範 2.1 版」A 級標準及國際 W3C WCAG 2.1/2.2 AA 規範設計：

  • 跳至主要內容區：網頁載入後，按一下 Tab 鍵即可浮現「跳至主要內容區」捷徑，按 Enter 可略過上方導覽列直接進入操作區。
  • 全鍵盤巡迴（Keyboard Navigable）：所有按鈕、輸入框、圖層標籤皆支援 Tab（前進）與 Shift + Tab（後退）循環焦點移動，並具備雙層高對比藍色光暈外框提示。
  • 螢幕報讀器相容：所有互動控制元件均具備清晰的 aria-label、role 與 aria-live 狀態屬性，視障輔具使用者能完整理解當前處方步驟與導航結果。
  • 觸控最小尺寸：所有按鈕與觸控標籤點擊區域皆大於 44×44 像素，友善長輩與行動裝置操作。

陸、常見問題與疑難排解 (FAQ)

Q1：系統是否必須具備 Google Maps API Key 才能使用？

不需要。本系統內建草屯鎮專屬實體路網拓撲圖（caotun-roads.js），即使未設定 API 金鑰或遇網路離線，仍可順暢進行距離排序、直線與路網道路路徑繪製。若有設定官方 API 金鑰，則可進一步享有路況即時動態到達時間、Google 官方地址電話自動帶入等進階雲端功能。

Q2：在「資料維護」模式修改新增的資料，換一台電腦還看得到嗎？

修改的資料會即刻保存在當前瀏覽器的本機快取中。若要在多台電腦間移轉，或提供給同仁使用，請於維護完成後點擊「💾 備份 KML 檔」匯出 KML 檔案；在另一台電腦開啟本系統後，點擊「📂 載入 KML 檔」載入該檔案，所有新增修改的點位與照片便會完整同步。

Q3：為什麼新增點位時系統提示「不在南投縣草屯鎮內」？

本系統內建南投縣草屯鎮官方界線多邊形座標（共 136 個邊界頂點），若搜尋或點選的座標位在芬園鄉、霧峰區或南投市等鄰近外鄉鎮，系統將基於轄區資料正確性自動阻擋，請確認選取座標確實位於草屯鎮內。

Q4：如何將生活處方地圖放上公所官網或大螢幕觸控機台？

本系統以標準 HTML5 + CSS + JavaScript 架構建置，可直接以 <iframe> 內嵌於南投縣政府、草屯鎮公所官網或衛生所宣導網頁中；亦支援電腦開機全螢幕（F11 鍵）放置於公所服務台作為大觸控螢幕生活處方導覽機使用。
